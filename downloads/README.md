# Vulto downloads

Public installers served from the landing page:

- `Vulto_1.0.0_x64-setup.exe` — Windows NSIS
- `Vulto_1.0.0_x64_en-US.msi` — Windows MSI
- `Vulto_1.0.0_amd64.AppImage` — Linux AppImage
- `Vulto_1.0.0_amd64.deb` — Linux Debian/Ubuntu package

Linux packages are produced by CI (`deploy-public.yml`) and synced here after each release / manual workflow run.
